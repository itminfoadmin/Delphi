3차 델파이 설문 방법 안내

설문을 시작하기 전에 아래 안내를 꼼꼼히 확인해주세요.

💡 설문 요약
3차 설문은 2차 설문 결과를 참고하여 평정지표의 적절성을 다시 5점 척도(1 매우 부적절 ~ 5 매우 적절)로 평정하는 설문입니다. 각 지표마다 2차 델파이 결과(평균, 표준편차, CVR, 본인의 이전 선택, 부적절 의견)가 함께 제시되며, 이를 참고하여 3차 평정을 진행하실 수 있습니다.

1화면 구성

설문 화면은 크게 상단 헤더, 평정지표 카드 3개, 좌우 이동 버튼으로 구성됩니다. 각 카드 헤더에는 「2차 델파이 결과」와 「3차 델파이(진행중)」 칼럼 라벨이 표시되어 있습니다.

상단 헤더 현재 페이지의 ID, 범주명, 글자 크기 조절 버튼, 저장 버튼, 나가기 버튼이 표시됩니다.
교육활동 카드 교육활동 평정지표, 2차 결과, 3차 평정 척도가 파란색 카드에 표시됩니다.
하화활동 카드 하화활동 평정지표, 2차 결과, 3차 평정 척도가 초록색 카드에 표시됩니다.
상구활동 카드 상구활동 평정지표, 2차 결과, 3차 평정 척도가 보라색 카드에 표시됩니다.

22차 델파이 결과 확인하기

각 지표의 중간 칼럼에 2차 델파이 결과가 시각적으로 표시됩니다. 이를 참고하여 3차 평정을 진행합니다.

← 2차 델파이 결과 (초록색 바와 원문자에 마우스를 올려보세요.)
M=값 해당 지표에 대한 2차 설문 결과 중 평균값(Mean)을 나타냅니다. 가로선 위에서 평균값과 그 상대적 위치가 표시됩니다.
초록 바 해당 지표에 대한 2차 설문 결과 중 표준편차(SD)의 범위를 나타냅니다. 평균을 중심으로 SD/2만큼 양쪽으로 표시됩니다. 해당 초록바에 마우스를 올리시면 SD값과 CVR값이 말풍선의 형태로 표시됩니다.
회색 원문자 해당 지표에 대한 패널의 2차 평정 값(선택)을 나타냅니다. 마우스를 올리면 "이전 선택"이라는 말풍선이 표시됩니다.
의견 조회 2차 델파이 설문에서 매우 부적절(1점) 또는 부적절(2점)이 선택되어 이에 대한 의견이 제시된 경우에 해당 지표 텍스트의 맨 끝에 (매우) 부적절 선택 의견(N건) 조회 버튼이 표시됩니다. 클릭하면 매우 부적절(1점)과 부적절(2점)에 대한 의견이 표시됩니다.

3지표 확인하기

각 카드에는 2차 델파이 설문에서 평정된 평정 지표가 왼쪽에 표시되고, 중간에 2차 델파이 결과, 오른쪽에 3차 적절성 평정 척도가 함께 제시됩니다. 카드 헤더에는 활동 유형명과 현재 요소명이 표시되어, 어떤 범주와 요소에 해당하는 지표를 보고 있는지 확인할 수 있습니다.

4적절성 평정하기

각 지표의 오른쪽에 ①~⑤ 원형 버튼이 점선으로 연결되어 표시됩니다. 2차 결과를 참고하여 해당 지표가 평정지표로서 얼마나 적절한지 판단하고 점수를 클릭합니다.

5부적절 판단 사유 입력

1점(매우 부적절) 또는 2점(부적절)을 선택하면 해당 지표 아래에 사유 입력란이 나타납니다. 해당 지표를 부적절하다고 판단하신 이유를 기술해주세요. 3점 이상을 선택하면 사유 입력란은 자동으로 숨겨집니다.

1점 선택 "매우 부적절로 판단하신 이유를 기술해주세요." 안내 문구가 표시됩니다.
2점 선택 "부적절로 판단하신 이유를 기술해주세요." 안내 문구가 표시됩니다.

6요소 설명 보기

각 카드 헤더에 있는 [☞ 요소 설명 보기] 버튼을 클릭하면, 해당 요소에 대한 상세 설명이 별도의 모달 창으로 표시됩니다. 이 모달은 마우스로 드래그하여 위치를 이동할 수 있어, 지표 내용과 설명을 동시에 확인할 수 있습니다. 모달 상단에는 글자 크기 조절 버튼(−/+)이 있어 내용을 확대·축소하여 볼 수 있습니다.

7저장 및 페이지 이동

화면 좌우의 이전(◁), 다음(▷) 화살표를 클릭하거나 키보드의 ← → 방향키를 사용하여 요소별 페이지를 이동합니다.

자동 저장 페이지를 이동할 때 현재 페이지의 평정 결과가 자동으로 저장됩니다.
미평정 안내 평정되지 않은 지표가 있는 상태에서 이동하면, 미평정 지표 수를 알리고 이동 여부를 확인하는 모달이 표시됩니다.
수동 저장 상단 헤더의 [저장] 버튼을 클릭하여 현재 페이지의 평정을 수동으로 저장할 수도 있습니다.

8글자 크기 조절

상단 헤더의 [−A], [A+] 버튼으로 카드 영역 전체의 글자 크기를 70%~140% 범위에서 조절할 수 있습니다. 현재 배율은 버튼 사이에 표시됩니다. 또한 [☞ 요소 설명 보기] 모달에서도 별도의 글자 크기 조절 버튼이 제공됩니다.

9나가기

화면 우측 상단에는 [나가기] 버튼이 있습니다. 전체 설문을 완료하지 못한 상태에서 중간에 종료할 때 사용합니다. 이미 저장된 평정 결과는 서버에 보존되므로, 다음에 다시 접속하면 이전 평정이 자동으로 복원되어 이어서 진행할 수 있습니다.

10설문 완료

마지막 요소 페이지에서 다음(▷) 버튼을 클릭하면 설문 완료 화면이 나타납니다. [설문 완료] 버튼을 클릭하면 3차 델파이 설문이 완료 처리되며, 설문 선택 화면으로 돌아갑니다. 모든 지표에 대해 미평정 항목이 있으면 완료할 수 없으므로, 모든 지표를 평정한 후 완료해주세요.

⚠ 주의사항
평정 결과는 페이지 이동 시 자동 저장되며, 브라우저를 닫거나 새로고침하더라도 이미 저장된 평정은 유실되지 않습니다. 다만 저장 버튼을 누르지 않고 페이지를 이탈하면 해당 페이지의 미저장 평정은 유실될 수 있으니, 중요한 평정 후에는 [저장] 버튼을 활용해주세요.
