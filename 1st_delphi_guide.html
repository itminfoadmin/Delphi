1차 델파이 설문 방법 안내

설문을 시작하기 전에 아래 안내를 꼼꼼히 확인해주세요.

💡 설문 요약
각 요소별로 제시된 교육활동·하화활동·상구활동 평정지표를 검토하고, 추가가 필요한 지표가 있으면 [평정 지표 추가하기]로 지표와 사유를 입력합니다. 모든 요소를 검토한 뒤 설문을 완료합니다.

1화면 구성

설문 화면은 크게 상단 헤더, 평정지표 카드 3개, 좌우 이동 버튼으로 구성됩니다.

상단 헤더 현재 페이지의 ID, 범주명, 글자 크기 조절 버튼, 나가기 버튼이 표시됩니다.
교육활동 카드 교육활동 평정지표가 파란색 카드에 표시됩니다.
하화활동 카드 하화활동 평정지표가 초록색 카드에 표시됩니다.
상구활동 카드 상구활동 평정지표가 보라색 카드에 표시됩니다.
진행 상태 상구활동 카드 아래 중앙에 현재 진행 상태(예: 1/19)가 표시됩니다.
교육활동
하화활동
상구활동

2지표 확인하기

각 카드에는 선행연구에서 탐색된 평정지표가 표시됩니다. 하나의 페이지에 교육활동, 하화활동, 상구활동의 평정 지표가 요소별로 함께 제시됩니다. 카드 헤더에는 활동 유형명과 (평정 요소) 표시와 함께 현재 요소명이 표시되어, 어떤 범주와 요소에 해당하는 지표를 보고 있는지 확인할 수 있습니다.

3지표의 맥락 보기

각 카드 헤더에 있는 [☞ 지표의 맥락 보기] 버튼을 클릭하면, 해당 지표에 대한 상세 설명이 별도의 모달 창으로 표시됩니다. 이 모달은 마우스로 드래그하여 위치를 이동할 수 있어, 지표 내용과 설명을 동시에 확인할 수 있습니다. 모달 상단에는 글자 크기 조절 버튼(−/+)이 있어 내용을 확대·축소하여 볼 수 있습니다. 모달 우측 상단의 [닫기] 버튼을 클릭하면 닫힙니다.

4평정 지표 추가하기

각 카드 헤더의 [＋ 평정 지표 추가하기] 버튼을 클릭하면 추가 지표 입력 창이 열립니다.

카드 헤더에서 [＋ 평정 지표 추가하기] 버튼을 클릭합니다.
모달 창에 추가 지표(지표명)를 입력합니다.
지표 설명(사유)에 해당 지표를 추가하는 이유를 입력합니다.
[추가] 버튼을 클릭하면 즉시 저장되고, 해당 카드의 지표 목록 하단에 표시됩니다.

추가된 지표는 [패널 추가 지표] 표시와 함께 기존 지표 아래에 나타나며, 각 추가 지표의 오른쪽에는 다음 버튼이 제공됩니다.

추가 사유 보기 추가 시 입력한 사유를 모달 창으로 확인합니다.
수정 추가한 지표명과 사유를 수정합니다.
삭제 추가한 지표를 삭제합니다. 삭제 전 확인 창이 표시됩니다.

5페이지 이동

화면 좌우의 이전(◁), 다음(▷) 화살표를 클릭하거나 키보드의 ← → 방향키를 사용하여 요소별 페이지를 이동합니다. 첫 번째 페이지에서는 이전 버튼이, 마지막 페이지 이후의 설문 완료 화면에서는 다음 버튼이 숨겨집니다.

6글자 크기 조절

상단 헤더의 [−A], [A+] 버튼으로 카드 영역 전체의 글자 크기를 70%~140% 범위에서 조절할 수 있습니다. 현재 배율은 버튼 사이에 표시됩니다. 또한 [☞ 지표의 맥락 보기] 모달에서도 별도의 글자 크기 조절 버튼이 제공됩니다.

7나가기

화면 우측 상단에는 [나가기] 버튼이 있습니다. [나가기] 버튼은 전체 설문을 완료하지 못한 상태에서 중간에 종료할 때 사용합니다. 완료되지 않은 설문은 이후에 다시 진행할 수 있습니다.

8설문 완료

마지막 요소 페이지에서 다음(▷) 버튼을 클릭하면 설문 완료 화면이 나타납니다. [설문 완료] 버튼을 클릭하면 1차 델파이 설문이 완료 처리되며, 설문 선택 화면으로 돌아갑니다. 완료 후에는 해당 설문에 다시 참여할 수 없으므로, 모든 요소를 확인한 후 완료해주세요.

⚠ 주의사항
설문 중 페이지를 이탈(브라우저 닫기, 새로고침 등)하더라도 이미 추가한 지표는 서버에 저장되어 있으므로 유실되지 않습니다. 단, 추가 모달에서 입력 중인 내용은 저장되지 않으니 반드시 [추가] 버튼을 눌러 저장해주세요.
