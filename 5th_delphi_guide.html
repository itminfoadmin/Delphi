5차 델파이 가중치 설문 방법 안내

설문을 시작하기 전에 아래 안내를 꼼꼼히 확인해주세요.

💡 설문 요약
5차 설문은 4차까지의 적절성 평정 결과를 참고하여 각 평정지표에 대한 가중치(Weight)를 5점 척도(1 매우 낮음 ~ 5 매우 높음)로 부여하는 설문입니다. 각 지표마다 4차 델파이 결과(평균, 표준편차, CVR, 본인의 이전 선택)가 함께 제시되므로, 이를 참고하여 가중치를 설정합니다.

1화면 구성

설문 화면은 크게 상단 헤더, 평정지표 카드 3개, 좌우 이동 버튼으로 구성됩니다. 각 카드 헤더에는 「4차 델파이 결과」와 「평정시 가중치 설정(진행중)」 칼럼 라벨이 표시되어 있습니다.

상단 헤더 현재 페이지의 ID, 범주명, 글자 크기 조절 버튼, 저장 버튼, 나가기 버튼이 표시됩니다.
교육활동 카드 교육활동 평정지표, 4차 결과, 가중치 설정 척도가 파란색 카드에 표시됩니다.
하화활동 카드 하화활동 평정지표, 4차 결과, 가중치 설정 척도가 초록색 카드에 표시됩니다.
상구활동 카드 상구활동 평정지표, 4차 결과, 가중치 설정 척도가 보라색 카드에 표시됩니다.

24차 델파이 결과 확인하기

각 지표의 중간 칼럼에 4차 델파이 결과가 시각적으로 표시됩니다. 이를 참고하여 가중치를 설정합니다.

M=3.0
▼
4
← 4차 델파이 결과 (초록색 바와 원문자에 마우스를 올려보세요.)
M=값 4차 설문의 평균(Mean)을 나타냅니다. 가로선 위에서 평균 위치에 M=값과 ▼ 화살표가 표시됩니다.
초록 바 4차 설문의 표준편차(SD) 범위를 나타냅니다. 평균을 중심으로 SD만큼 양쪽으로 표시됩니다. 마우스를 올리면 SD값과 CVR값이 말풍선으로 표시됩니다.
회색 원 본인의 4차 평정값을 나타냅니다. 마우스를 올리면 "이전 선택"이라는 말풍선이 표시됩니다.

3지표 확인하기

각 카드에는 4차까지 평정된 평정지표가 왼쪽에 표시되고, 중간에 4차 결과, 오른쪽에 가중치 설정 척도가 함께 제시됩니다. 카드 헤더에는 활동 유형명과 현재 요소명이 표시되어, 어떤 범주와 요소에 해당하는 지표를 보고 있는지 확인할 수 있습니다.

5요소 설명 보기

각 카드 헤더에 있는 [☞ 요소 설명 보기] 버튼을 클릭하면, 해당 요소에 대한 상세 설명이 별도의 모달 창으로 표시됩니다. 이 모달은 마우스로 드래그하여 위치를 이동할 수 있어, 지표 내용과 설명을 동시에 확인할 수 있습니다. 모달 상단에는 글자 크기 조절 버튼(−/+)이 있어 내용을 확대·축소하여 볼 수 있습니다.

6저장 및 페이지 이동

화면 좌우의 이전(◁), 다음(▷) 화살표를 클릭하거나 키보드의 ← → 방향키를 사용하여 요소별 페이지를 이동합니다.

자동 저장 페이지를 이동할 때 현재 페이지의 가중치 설정이 자동으로 저장됩니다.
미설정 안내 가중치가 설정되지 않은 지표가 있는 상태에서 이동하면, 미설정 지표 수를 알리고 이동 여부를 확인하는 모달이 표시됩니다.
수동 저장 상단 헤더의 [저장] 버튼을 클릭하여 현재 페이지의 가중치를 수동으로 저장할 수도 있습니다.

7글자 크기 조절

상단 헤더의 [−A], [A+] 버튼으로 카드 영역 전체의 글자 크기를 70%~140% 범위에서 조절할 수 있습니다. 현재 배율은 버튼 사이에 표시됩니다. 또한 [☞ 요소 설명 보기] 모달에서도 별도의 글자 크기 조절 버튼이 제공됩니다.

8나가기

화면 우측 상단에는 [나가기] 버튼이 있습니다. 전체 설문을 완료하지 못한 상태에서 중간에 종료할 때 사용합니다. 이미 저장된 가중치 설정은 서버에 보존되므로, 다음에 다시 접속하면 이전 설정이 자동으로 복원되어 이어서 진행할 수 있습니다.

9설문 완료

마지막 요소 페이지에서 다음(▷) 버튼을 클릭하면 설문 완료 화면이 나타납니다. [설문 완료] 버튼을 클릭하면 5차 델파이 가중치 설문이 완료 처리되며, 설문 선택 화면으로 돌아갑니다. 모든 지표에 대해 가중치가 설정되지 않은 항목이 있으면 완료할 수 없으므로, 모든 지표의 가중치를 설정한 후 완료해주세요.

⚠ 주의사항
가중치 설정은 페이지 이동 시 자동 저장되며, 브라우저를 닫거나 새로고침하더라도 이미 저장된 설정은 유실되지 않습니다. 다만 저장 버튼을 누르지 않고 페이지를 이탈하면 해당 페이지의 미저장 설정은 유실될 수 있으니, 중요한 설정 후에는 [저장] 버튼을 활용해주세요.
